# 许可证决策

**状态：已确认 — MIT**（2026-11-18）。仓库根目录已加入 `LICENSE`。

候选方案与取舍：

| 许可证 | 适合什么 | 需要注意 |
| --- | --- | --- |
| MIT | 希望脚本和模板被广泛使用、改动、商用 | 几乎不保留限制，署名要求最轻 |
| Apache-2.0 | 同时关心专利授权与明确的权利边界 | 文本较长，需要保留 NOTICE 约定 |
| CC BY 4.0 | 主要把这里当作文章与实验笔记 | 对软件代码不如 MIT / Apache 常见 |
| CC BY-NC-SA 4.0 | 不想让内容被商业转载 | 会限制他人商用，包括很多二次创作 |

补充说明：

- 仓库里既有文档也有可运行脚本。如果最后选择"文档与代码分开授权"，需要在 README 和各目录里分别说明，不能只放一个顶层 LICENSE。
- `prompts/` 里的模板是从真实工作流里提炼的脱敏版本，是否一并开放复用也要一起确认。
- 确定后在仓库根目录加入 `LICENSE`（或 `LICENSE-CODE` / `LICENSE-DOCS`），并更新 README 的「许可证」段落。

决定记录：主人于 2026-11-18 确认采用 MIT，已加入顶层 `LICENSE`，文档与脚本统一适用。

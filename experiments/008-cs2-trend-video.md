# 008 · CS2 价格走势视频：真实数据到确定性渲染

**状态**：✅ 已验证（公开仓库） ｜ 📋 本人操作细节待整理

> 来源：<https://github.com/jiuhuweisi-maker/cs2-skin-price-trend>（2026-11-18 验证 HTTP 200）。以下是仓库中可核对的事实，不是本人重写一遍的成果。

## 目标

把两件 CS2 饰品的真实历史价格，做成一条 90 秒 1080p 动态走势视频。

## 环境

- Node.js 脚本构建数据；Chromium / Edge 开 CDP（`--remote-debugging-port=9333`）逐帧截图；ffmpeg 合成 MP4。
- 数据来自公开页面真实抓取，无模拟数据。

## 实际步骤（公开仓库记录）

1. `node scripts/build-cs.js`：原始 JSON → 月度 CSV。
2. `node scripts/export-json.js`：CSV → `web/chart.json`。
3. `node scripts/render.js`：逐帧截图 → ffmpeg 合成 MP4。
4. 页面暴露 `window.__renderAt(t)`，同一 `t` 永远画同一帧，保证渲染确定性。

## 实际结果（公开仓库记录）

- 成片：`1920×1080 / 30fps / 90s / H.264`。
- 双 Y 轴折线（两件饰品价差 10 倍以上，共用轴会压扁）、时间轴逐帧推进、底部 KPI 实时滚动、关键事件标注、结尾总结卡。
- 区间 58 个月无缺口；原始点数与月度口径写在仓库数据中。
- 渲染支持断点续传，单帧失败重试并自动重载页面。

## 失败经验（公开仓库记录）

- BUFF 历史接口硬上限 365 天，传更大的 `days` 也只返回 365 → 换数据源并说明，不硬凑。
- 系统代理导致某站点 TLS 握手失败 → 该源直连，另一源走代理，按站点分开处理。
- 未登录返回 `Login Required` → 从已登录浏览器导出会话凭据（凭据不进仓库）。
- 币种切换走表单 POST，带表单令牌与方法覆盖字段。
- 异常成交价混进数据 → 按月中位数过滤，过滤条数写入 CSV。
- 整月无成交 → 图上留空，不插值、不拟合。

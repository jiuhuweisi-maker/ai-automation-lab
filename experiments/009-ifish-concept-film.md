# 009 · IFISH 概念片：GPT 生图 + 二维运动设计

**状态**：✅ 已验证（公开仓库） ｜ 📋 本人操作细节待整理

> 来源：<https://github.com/jiuhuweisi-maker/IFISH-v5>（2026-11-18 验证 HTTP 200）。

## 目标

83 秒角色概念宣传片，1920×1080 / 60fps，包含成片、GPT 生图素材、二维运动设计、完整渲染代码与检查记录。

## 环境

- Windows、Python 3.11+、支持 OpenGL 3.3 的显卡、带 NVENC 的 FFmpeg。
- 字体用 Windows 系统字体；依赖版本已记录在公开仓库。

## 实际步骤（公开仓库记录）

1. `python work/render_v5.py --preview-only`：生成镜头总览与封面。
2. `python work/render_v5.py`：输出完整影片。
3. `python work/verify_v5.py`：检查时长、解码、音轨与逐帧。
4. `python work/export_mark.py`：导出标志。

## 实际结果（公开仓库记录）

- 成片 83.000 秒、4980 帧，完整解码无错误，保留参考片连续原音轨。
- 三项新动作素材（引导、吃饭、编程）由 GPT 生图生成，三色基础图沿用同系列素材，六张素材与完整提示词在 `work/native_prompts_v5.json`。
- 动画手法：平面路径形变、动态排字、移动图形遮罩、角色局部二维网格形变；8 倍空间抗锯齿、每帧 3 个时间采样；九处段落交接用 1.12 秒移动遮罩。
- `SHA256SUMS.txt` 记录交付文件哈希。

## 失败经验 / 边界

- 重渲染只使用仓库内素材与音轨，不调用生图服务、不需要 API 密钥——避免把凭据写进流程。
- 角色原始形象来自用户提供的图片，配乐为第三方参考音轨；**仓库公开不代表第三方素材有开放授权**，权利归各自权利人。
- 片中算式、文案、代码与翻译为概念演示，不是产品能力证明。

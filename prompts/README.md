# 提示词模板

这里放的是**脱敏后的结构**，不是可以直接复制出成果的魔法咒语。使用时按自己的项目填空。

## 使用原则

- **不要填真实秘密进去。** API Key、Token、Cookie、SSH 私钥、服务器地址、代理节点都不属于提示词内容。
- **一次一个任务。** 提示词越长、目标越多，结果越难验收。
- **写清验收条件。** 没有验收条件的提示词只能产出"看起来对"的东西。
- **保留原文出处。** 让模型对摘要类任务附引文，方便回查。
- **先小样本。** 新模板先拿一小段真实输入试，再扩大范围。

## 模板清单

| 文件 | 用途 |
| --- | --- |
| `bounded-subtask.md` | 把一个小子任务交给另一个 Agent 时用的派发骨架 |
| `experiment-note.md` | 写实验记录时用的结构，强制区分已验证与未完成 |

## 与仓库其他部分的关系

`bounded-subtask.md` 对应 [隔离派发工作流](../workflows/isolated-dispatch.md)；`experiment-note.md` 对应 `experiments/` 里的三篇记录。

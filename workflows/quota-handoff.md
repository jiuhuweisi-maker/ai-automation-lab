# 工作流：额度守护与接手

来源：[实验 003](../experiments/003-multi-agent-collaboration.md)。状态：✅ 本地演练已验证；真实线上重置时刻的观察尚未做。

## 适用范围

当一个工作流同时具备「主 Agent 有额度上限」和「可以改派给轻量 Agent」时使用。目的是在额度低时**主动切换**，而不是等调用失败。

## 数据来源

只读会话 JSONL 里的服务端额度快照，取主窗口与周窗口中**较低的剩余百分比**。

- 零模型调用、零网络访问。
- 不读聊天正文、凭据或密钥。
- 快照是服务端下发的**历史值**：不是实时余额，也不是账单。UI 显示已用完时以 UI 为准。

## 判定与动作

| 状态 | 判定 | 动作 |
| --- | --- | --- |
| `ok` | 剩余 ≥ 10% | 常规分流。 |
| `low` / `exhausted` | 剩余 < 10% 或已用尽 | 输出接手提示；轻量任务改派；硬拦主 Agent 的云端调用。 |
| `stale` | 快照过期且未到重置时间 | 保守继续接手，直到拿到新快照。 |
| `reset_due` | 已过重置时间但无新快照 | 自动解除，不冒充额度充足。 |
| `unknown` | 无可读快照 | 不冒充额度充足，云端任务先确认。 |

## 关键边界

- 高风险类（架构、安全、数据库、生产、高风险文件操作）**不随额度改变路线**，始终走高级模型或人工。
- 恢复到阈值以上自动解除，无需再次确认。
- 状态文件镜像到纯 ASCII 路径，避免在脚本里嵌入中文路径。
- 接手提示在准备任务时注入提示词首段，这样隔离环境里的 Agent 不必读工作区外的文件。
- **不改变**默认模型、服务档位、配置文件或凭据；不注册计划任务、不常驻服务。

## 边界说明

轻量 Agent 没有常驻感知额度的能力。「主动提示」由三处配合实现：主 Agent 每轮开局读状态、路由器每次调用读状态并打印提示、可选的桌面提醒。路由器只负责拦截和给出交接入口，实际派发仍由主 Agent 按授权完成。

# 方向 9 · AI 工具与工作流

**状态**：✅ 已验证（环境审计） ｜ 📋 持续优化中

## 涉及内容

Skills、MCP、提示词工程、成本与效率优化。

## 已验证（2026-11-15 本地环境审计）

- **Skills**：磁盘 101 份；当前桌面聊天提供 58 个，本地通用工作区 52 个，内层工作区 14 个；按文件去重 80 份。1 组同功能双版本，加载错误 0。
- **MCP**：用户配置 2 → 3 个；全局目录 6 个 + 项目独有 1 个 = 7 个，0 个同名重复，启用项均能返回工具目录。
- **Windows-MCP 0.8.9**：独立启动枚举到 10 个 GUI 工具，实测完成状态读取、打开记事本、输入、回读、撤销、关闭；启动并列出工具 10.28 秒；测试后 0 残留进程、0 同名开机任务。
- **Token 效率**：48 个 rollout 文件（47 个有效），本地记录按采样口径汇总；已证实同一任务内 107 次相同参数轮询、最大单条工具结果约 53.4 MB。结论区分「已证实 / 高概率 / 仅有潜力」，不把潜力写成节省。
- **提示词工程**：公开仓库 `dsh-prompt-kit` 把模糊需求拆成数据契约 / 视觉规格 / 渲染管线 / 验收清单，实战拦下三类问题。
- **成本守护**：额度低于阈值时拦截云端调用并改派本地 / 独立通道，见 [额度工作流](../../workflows/quota-handoff.md)。

## 方法论结论

- 按状态查询与目标区域截图，不一上来取整页 UI 树（纯状态 442 字节 vs 带 UI 树 43,847 字节）。
- 工具重叠时按触发条件选一条流程，不叠加。
- 缓存与摘要按工作区隔离，关键结论回查源文件。
- 同一任务跨层只优化一次提示词。

## 已验证的方法

- 三层分离：代码进 Git，配置在仓库外权限 600，状态单独打包。
- 先 `--check` 干跑，再真跑；构建产物逐文件验指纹。
- 锁自动更新、共存检查（同名端口 / 卷 / 单元被占就拒绝）。
- 按顺序验收，任一项不对不上线。

## 故障排查经验（公开复盘）

- 不反复重启主服务；内存见底时不降低 `swappiness`。
- 区分本地故障与上游故障，要同时看官方状态页和服务日志。
- 校验清单用二进制写回 LF，避免 CRLF 误报。
